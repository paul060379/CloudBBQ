## 玩法與功能

中英雙語，支援手機與桌面瀏覽器，免費部署於 GitHub Pages。
A bilingual (繁體中文 / English) barbecue game for phone and desktop browsers, hosted free on GitHub Pages.

- 拖食材上烤網、點按翻面、拖熟食給小動物，也能全程點按操作
- 輸入大廚名稱，慢慢烤或挑戰 90 秒派對
- 原創 Web Audio 音效：滋滋、翻面、蜂蜜、搧風、上菜與完成旋律
- IndexedDB 保存名字與每場分數，兩個模式分開顯示個人最高分
- 90 秒最高分僅計入完整結束場次；慢慢烤每次上菜都會保存
- 烤到剛剛好會進入短暫的 ✨ Perfect 時機，連續 Perfect 會跳出 PERFECT 連段
- 遊戲中會隨機冒出小劇場對白，會看目前狀況說話；90 秒結束後給一個搞笑今日稱號
- PNG 成績分享卡：支援檔案分享的手機使用分享選單，其他裝置下載圖片

## 多語系 / Languages

所有文案集中在 `i18n.js` 的 `zh` 與 `en` 兩份字典，兩邊的 key 必須一致。
靜態文字用 `data-i18n`（文字）、`data-i18n-html`（含標籤）、`data-i18n-attr="屬性:key;…"`（屬性）標記；
動態文字呼叫 `PicnicI18n.t(key, params)` 或 `PicnicI18n.set(node, key, params)`，`{name}` 佔位符會被 `params` 取代。

預設是中文，不看瀏覽器語言。玩家按過切換鈕後，選擇會記在 `localStorage` 的 `picnic-lang`，之後每次進入都沿用。
起始頁與遊戲標題列各有一顆 🌐 切換鈕；切換時會重新套用 DOM、更新 `<html lang>`，並發出 `picnic-lang-change` 事件讓 `game.js` 重畫動態文字。
新增語言：在 `i18n.js` 複製一份字典、加進 `tables`，其餘程式不需更動。

## 本機紀錄

資料只存在目前瀏覽器，清除網站資料會遺失，不會自動上傳。
`storage.js` 封裝 IndexedDB；每場紀錄包含穩定 UUID、玩家名字、模式、分數、分享份數、開始與更新時間、是否完成，以及遊戲版本。
未來可在此層加入使用者主動選擇的雲端同步；目前沒有伺服器或線上排行榜。

## 部署

根目錄即完整靜態網站，無需安裝套件或後端。
GitHub Pages 使用 main 分支的根目錄。音效由瀏覽器即時合成，沒有外部音效下載。

## 音效與分享相容性

音效按使用者點按啟動；等待 AudioContext 成功恢復後才播放，支援的 Safari 使用 playback 音訊類型。起始頁提供試聽及狀態提示。
成績分享先預覽圖片，再由明確點按開啟原生分享；取消不會下載，失敗時可用儲存連結或長按圖片。
成績卡文字跟著目前語言，換行會保留英文單字不被切斷。

## 測試

回歸檢查 / Regression suite：`node --test regressions.test.cjs`

涵蓋音效啟動、分享流程、兩份字典 key 一致、程式與 HTML 用到的 key 都有定義、預設語言與切換後的記憶。
